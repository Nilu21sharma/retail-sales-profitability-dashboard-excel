# Retail Sales & Profitability Dashboard Using Excel

## Project Overview

This project analyses retail sales and profitability data using Microsoft Excel.

The aim is to build an interactive dashboard that helps business users understand sales performance, profitability, customer segments, product categories, regional performance and the impact of discounts.

---

# 1. Business Problem

A retail business has a large amount of transaction data but needs a simple way to understand business performance.

The main questions are:

- How much sales and profit are we generating?
- Which regions perform best?
- Which categories and products are most profitable?
- Which customer segments generate the most revenue?
- Are discounts affecting profitability?
- Which areas require further investigation?

The key business issue is that high sales do not always mean high profit.

---

# 2. Project Objectives

The dashboard will be designed to:

- Monitor sales and profit KPIs
- Analyse sales and profit trends
- Compare regional performance
- Analyse category and sub-category performance
- Understand customer segment contribution
- Analyse discount impact
- Identify high-performing and loss-making products
- Provide actionable business recommendations

---

# 3. Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- KPI Cards
